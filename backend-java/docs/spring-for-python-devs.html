언어 기초 ①

Java는 컴파일 + 정적 타입 언어

  • Python은 실행하며 해석(interpret). Java는 먼저 컴파일해서 실행합니다.
  • 모든 변수는 타입을 미리 선언합니다. (파이썬 타입힌트가 "필수"가 된 버전)
  • 타입이 틀리면 실행 전에 컴파일 에러로 막아줍니다 — 든든한 안전망.
용어: JDK · JVM · 바이트코드
JVM(자바 가상 머신) = 자바 프로그램이 도는 런타임. 바이트코드 = 소스를 컴파일한 중간 결과물(.class), JVM이 이걸 실행. JDK = 컴파일러+JVM+도구 묶음, 개발에 필요한 설치본. 이 프로젝트는 JDK 21 필요.

언어 기초 ②

문법 대조: 같은 함수, 다른 옷

Python
def greet(name: str) -> str:
    # 들여쓰기로 블록 구분
    return f"안녕, {name}"
Java
String greet(String name) {
    // 중괄호로 블록, 끝에 세미콜론
    return "안녕, " + name;
}
  • 반환 타입이 함수 이름 앞에 옵니다 (String greet).
  • 블록은 { }, 문장 끝은 ; — 들여쓰기는 가독성용일 뿐 문법이 아닙니다.

Spring Boot

스프링의 핵심: 객체를 대신 만들어 주는 컨테이너

  • 당신이 new로 객체를 안 만들어도, 스프링이 만들어 보관합니다.
  • 이 "스프링이 관리하는 객체"를 빈(Bean)이라 부릅니다.
  • 필요한 곳에 빈을 자동으로 꽂아줍니다 → 이게 의존성 주입(다음 장).
용어: IoC 컨테이너 · 자동 설정
IoC(제어의 역전) = "객체 생성·연결을 내가 아니라 프레임워크가 한다". 그 객체들을 담는 통이 컨테이너. 자동 설정 = starter만 넣으면 DB·웹서버 기본 세팅을 스프링이 알아서 — @SpringBootApplication 한 줄이 시동을 겁니다.

어노테이션

어노테이션 @ = 데코레이터 @의 사촌

Python 데코레이터
@app.post("/login")
async def login(...):
    ...
Java 어노테이션
@PostMapping("/login")
TokenResponse login(...) {
    ...
}
차이 한 줄
데코레이터는 함수를 감싸 실행을 바꾸지만, 어노테이션은 그 자체로는 아무 일도 안 하는 "표식"입니다. 스프링이 시동 시 이 표식을 읽고(reflection) 동작을 연결합니다.

의존성 주입 (DI)

생성자에 적으면 스프링이 꽂아준다

auth/AuthService.java
@Service                          // "이건 서비스 빈"
public class AuthService {
  private final UserRepository repo;

  // 생성자 — 스프링이 UserRepository 빈을 자동 전달
  public AuthService(UserRepository repo) {
    this.repo = repo;
  }
}
  • @Service @Repository @RestController @Component 가 붙으면 빈으로 등록됩니다.
  • 파이썬에선 직접 AuthService(repo) 했지만, 여기선 연결을 프레임워크가 합니다.

ORM = 객체↔테이블 자동 변환(SQLAlchemy가 하던 일). JPA = 자바의 ORM 표준(규격), Hibernate = 그 표준의 실제 구현체. extends BaseEntity로 UUID·생성시각을 상속받습니다.

Lombok

Lombok = 보일러플레이트 자동 생성기

  • 자바는 필드마다 getter/setter를 손으로 쓰는 문화가 있습니다 (지루함).

public class User extends BaseEntity { ... }

Repository

메서드 이름만 적으면 쿼리가 생긴다

repository/UserRepository.java
public interface UserRepository
        extends JpaRepository<User, UUID> {

  Optional<User> findByEmail(String email);
  boolean existsByEmail(String email);
}
  • 구현 코드가 없습니다. 스프링이 메서드 이름을 파싱해 SQL을 만들어 줍니다.
  • save() findById() findAll() delete() 는 JpaRepository에서 공짜로 상속.
용어: interface · Optional
interface = 메서드 "약속"만 적은 틀(구현 없음). Optional<User> = "User일 수도, 없을 수도" — 파이썬의 User | None을 안전하게 다루는 상자.

DTO & record

record = Pydantic 모델의 자바판

class UserRegister(BaseModel):

auth/dto/RegisterRequest.java
public record RegisterRequest(
  @Email String email,

용어: DTO · record · Bean Validation
DTO = 계층 간 데이터 운반용 객체. record = 불변 데이터 클래스(자바 16+), Pydantic처럼 간결. @Email @Size = Bean Validation — 컨트롤러에서 @Valid로 자동 검증됩니다.

Controller

@RestController = FastAPI router

auth/AuthController.java
@RestController
@RequestMapping("/api/auth")      // 공통 경로 prefix
public class AuthController {

  @PostMapping("/login")          // POST /api/auth/login
  TokenResponse login(@Valid @RequestBody LoginRequest req) {
    return authService.login(req);
  }
}
  • @RequestBody = 요청 JSON을 객체로(파이썬은 함수 인자 타입으로 자동).
  • 반환한 객체는 스프링이 JSON으로 직렬화해 응답합니다.

Service & 트랜잭션

@Transactional 한 줄의 마법

auth/AuthService.java
@Transactional                  // 이 메서드 = 하나의 DB 트랜잭션
public User register(RegisterRequest req) {
  if (repo.existsByEmail(req.email()))
    throw new ApiException(CONFLICT, "이미 등록된 이메일");
  return repo.save(...);    // 성공하면 commit, 예외면 자동 rollback
}
용어: 트랜잭션 · throw
트랜잭션 = "전부 성공 or 전부 취소". 메서드 안에서 예외가 나면 DB 변경이 자동 롤백됩니다. throw = 파이썬 raise. SQLAlchemy에서 session.commit()을 손으로 부르던 걸 어노테이션이 대신합니다.
